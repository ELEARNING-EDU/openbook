# OpenBook Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trình đọc EPUB mở ngay trong trang chi tiết sách (iPad/máy tính) với lật trang curl/slide kiểu Apple Books; điện thoại được mời mở sách trong ứng dụng OpenBook.

**Architecture:** Server chỉ thêm trường `epubUrl`, Server Action `recordRead` và route proxy `/books/[slug]/epub`. Mọi xử lý EPUB (giải nén, đọc OPF/TOC, lọc HTML, phân trang) chạy ở client trong các module thuần có test (`src/lib/epub/*`, `src/lib/reader/*`); UI trình đọc là client component tải động.

**Tech Stack:** Next.js 16 (cacheComponents), Mongoose, Zod 4, `fflate`, `dompurify`, `page-flip`, Vitest (+ `jsdom` cho test DOM), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-30-reader-design.md` (mở rộng `docs/superpowers/specs/2026-10-29-openbook-design.md`)

## Global Constraints

- Điện thoại: `Math.min(innerWidth, innerHeight) < 600`, kiểm tra lúc bấm nút (client).
- `epubUrl`: `""` hoặc URL http/https có hostname tên miền — dùng lại `httpUrl` trong `src/lib/validation.ts`.
- Proxy: chỉ URL trong DB; timeout 15 000 ms; tối đa 20 MB (`20 * 1024 * 1024`); `Content-Type: application/epub+zip`; `Cache-Control: public, max-age=86400, s-maxage=86400`; 404 / 413 / 502 `"Không tải được sách"`.
- Env: `NEXT_PUBLIC_APP_BOOK_URL` (chứa `{slug}`), `NEXT_PUBLIC_APP_STORE_URL`, `NEXT_PUBLIC_PLAY_STORE_URL`; biến rỗng → ẩn nút.
- Cỡ chữ `[16, 18, 20, 22, 24]` px, mặc định 18. Nền: `white` `#ffffff`/`#1f1f1f`, `sepia` `#f6efe0`/`#5b4636`, `dark` `#1c1c1e`/`#e5e5e7`. Kiểu lật `curl` (mặc định) | `slide`.
- Chữ trong trình đọc: tiêu đề `var(--font-playfair)`, nội dung `Georgia, serif`, căn đều, `hyphens: auto`. Nền mặc định `sepia` (spec không chốt; hợp tông kem của website).
- Hai trang khi khung đọc rộng ≥ 1024 px. Khung `85vh`. Thanh công cụ tự ẩn sau 3 000 ms. Slide transition 300 ms.
- localStorage: `openbook:reader:settings` = `{ fontSize, theme, flip }`; `openbook:reader:pos:<slug>` = `{ chapter, progress }` (progress 0–1).
- `prefers-reduced-motion` → buộc slide, không animation.
- Mở trình đọc tăng `downloadCount` 1 lần (qua `recordRead`); route epub không tăng.
- Mọi chữ hiển thị tiếng Việt. Không `dangerouslySetInnerHTML` với HTML chưa qua `sanitizeChapter`.

## Review Focus

1. EPUB có chương chứa `<script>`, `<img onerror>`, `<a href="javascript:">`, `<style>` → không chạy script, không đổi giao diện website. (Task 3)
2. EPUB không có `nav` lẫn `toc.ncx`, hoặc đường dẫn tương đối kiểu `../Text/ch1.xhtml#p3`, hoặc tên file có dấu cách/ký tự mã hoá `%20` → vẫn mở được, mục lục dùng "Chương N". (Task 3)
3. Vị trí lưu hỏng hoặc vượt số chương (sách đổi file) → mở từ đầu, không trắng trang. (Task 4)
4. Nguồn EPUB chậm/không có `Content-Length`/lớn hơn 20 MB → trình đọc báo lỗi có nút Thử lại, server không treo. (Task 2)
5. Xoay iPad / đổi kích thước cửa sổ / đổi cỡ chữ giữa chừng → phân trang lại và ở đúng đoạn đang đọc. (Task 4, Task 6)

### Task 2: Route proxy `/books/[slug]/epub`

**Files:**
- Create: `src/lib/epub-proxy.ts`, `src/app/(site)/books/[slug]/epub/route.ts`
- Test: `tests/unit/epub-proxy.test.ts`

**Interfaces:**
- Consumes: `Book` model, `connectDB`
- Produces:
  - `MAX_EPUB_BYTES = 20 * 1024 * 1024`, `EPUB_TIMEOUT_MS = 15_000`
  - `proxyEpub(url: string, fetchImpl: typeof fetch = fetch): Promise<Response>` — trả Response cuối cùng cho client (200 stream / 413 / 502)
  - `getEpubUrl(slug: string): Promise<string | null>` (null nếu không có sách hoặc `epubUrl` rỗng)

- [ ] **Step 1: Test thất bại** (`fetchImpl` giả, không gọi mạng):
  - nguồn 200, body 3 byte → status 200, header `content-type` `application/epub+zip`, `cache-control` đúng hằng số, body bằng 3 byte đó.
  - nguồn `Content-Length: 30000000` → 413, không đọc body.
  - nguồn không có `Content-Length`, stream 21 MB → đọc response bị lỗi/ngắt (`await res.arrayBuffer()` rejects).
  - nguồn 500 → 502 body `"Không tải được sách"`; `fetchImpl` throw (timeout/AbortError) → 502.
  - nguồn redirect tới `ftp:` (`res.url` không http/https) → 502.
  - `getEpubUrl`: sách có `epubUrl` → URL; `epubUrl` rỗng hoặc slug lạ → `null` (dùng `setupTestDB()`).
- [ ] **Step 2:** `npm test -- epub-proxy` → FAIL.
- [ ] **Step 3: Cài đặt.** `fetchImpl(url, { signal: AbortSignal.timeout(EPUB_TIMEOUT_MS), redirect: "follow" })`; giới hạn byte bằng `TransformStream` đếm chunk và `controller.error()` khi vượt. Route: `GET(_req, ctx: RouteContext<"/books/[slug]/epub">)` → `getEpubUrl` → 404 `"Không tìm thấy"` hoặc `proxyEpub`.
- [ ] **Step 4:** `npm test` → PASS.

### Task 3: Đọc & lọc EPUB (client lib)

**Files:**
- Create: `src/lib/epub/parse.ts`, `src/lib/epub/sanitize.ts`, `tests/helpers/epub.ts`
- Test: `tests/unit/epub-parse.test.ts`, `tests/unit/epub-sanitize.test.ts` (đầu file `// @vitest-environment jsdom`)
- Deps: `npm i fflate dompurify page-flip` · `npm i -D jsdom`

**Interfaces:**
- Produces:
  - `type TocItem = { label: string; chapter: number; children: TocItem[] }`
  - `type EpubBook = { title: string; chapters: { href: string }[]; toc: TocItem[]; chapterHtml(i: number): string; resource(path: string): Uint8Array | undefined; chapterIndexOf(href: string): number }` — `href` là đường dẫn đầy đủ trong zip
  - `openEpub(data: ArrayBuffer | Uint8Array): EpubBook` — throw `new Error("EPUB_INVALID")` khi không phải zip / thiếu container / thiếu OPF / spine rỗng
  - `resolvePath(baseHref: string, relative: string): string` (bỏ `#fragment`, xử lý `..`, `decodeURIComponent`)
  - `sanitizeChapter(xhtml: string, opts: { baseHref: string; imageUrl(path: string): string | undefined; chapterIndexOf(href: string): number }): string`
  - `tests/helpers/epub.ts`: `makeEpub({ chapters: { name: string; html: string }[]; nav?: boolean; ncx?: boolean; images?: Record<string, Uint8Array> }): Uint8Array` dùng `fflate.zipSync` (OPF tại `OEBPS/content.opf`, chương tại `OEBPS/Text/<name>`)

- [ ] **Step 1: Test thất bại**
  - `openEpub(makeEpub({ chapters: [a, b], nav: true }))` → `chapters.length === 2`, `toc[0].label` lấy từ nav, `toc[1].chapter === 1`.
  - chỉ `ncx: true` → toc từ ncx; không nav lẫn ncx → toc `["Chương 1", "Chương 2"]`.
  - `openEpub(new Uint8Array([1,2,3]))` throws `EPUB_INVALID`; zip thiếu `META-INF/container.xml` throws `EPUB_INVALID`.
  - `resolvePath("OEBPS/Text/ch2.xhtml", "../Images/a%20b.png#x")` → `"OEBPS/Images/a b.png"`.
  - `chapterIndexOf("OEBPS/Text/ch2.xhtml")` → 1; không có → -1.
  - sanitize: `<p onclick="x">Hi</p><script>alert(1)</script><style>body{}</style>` → không chứa `script`, `style`, `onclick`; còn `<p>Hi</p>`.
  - `<img src="../Images/a.png" onerror="x">` với `imageUrl` trả `"blob:1"` → `src="blob:1"`, không `onerror`; `imageUrl` trả `undefined` → img bị xoá.
  - `<a href="javascript:alert(1)">` → không còn `href`; `<a href="https://x.org">` → `target="_blank"` + `rel="noopener noreferrer"`; `<a href="ch2.xhtml#p">` → `data-chapter="1"`, không `href`.
  - `<p style="color:red">` → không còn `style`.
- [ ] **Step 2:** `npm test -- epub` → FAIL.
- [ ] **Step 3: Cài đặt.** `fflate.unzipSync`; XML bằng `DOMParser` (`application/xml` cho OPF/NCX/nav, `application/xhtml+xml` → fallback `text/html` khi parse lỗi). Sanitize: `DOMPurify.sanitize(body.innerHTML, { FORBID_TAGS: ["style","link","iframe","object","embed","form","input","button","svg","math"], FORBID_ATTR: ["style"], ALLOW_DATA_ATTR: false })` rồi duyệt `img`/`a` để viết lại `src`/`href` như test.
- [ ] **Step 4:** `npm test` → PASS.
- [ ] **Step 5: Commit** `feat: add client EPUB parsing and sanitizing`
