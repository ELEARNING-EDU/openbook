# OpenBook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Website thư viện sách mở (metadata + link ngoài), người đọc đăng nhập Google để đánh giá/bình luận, admin quản lý sách/thể loại/bình luận.

**Architecture:** Một app Next.js App Router. Đọc dữ liệu trong Server Components qua `src/lib/queries.ts`; ghi dữ liệu qua Server Actions trong `src/actions/*`, mỗi action tự kiểm tra quyền. Logic thuần (slug, rating, validation, admin) tách riêng để unit test; truy vấn/action test bằng `mongodb-memory-server`.

**Tech Stack:** Next.js (latest, App Router, TS, `src/`), Tailwind CSS v4, Mongoose, `mongodb` + `@auth/mongodb-adapter`, `next-auth` v5, Zod, Vitest + mongodb-memory-server, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-29-openbook-design.md`

## Global Constraints

- Màu: nền `#FBF6EC`, chữ `#3B2A1A`, nhấn `#C2410C`, phụ `#4D7C0F`; font Playfair Display (tiêu đề), Be Vietnam Pro (nội dung, subset `vietnamese` + `latin`) qua `next/font/google`.
- Mọi chữ hiển thị bằng tiếng Việt.
- Env: `MONGODB_URI`, `AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `ADMIN_EMAILS` (phân cách dấu phẩy, so sánh không phân biệt hoa thường). Không commit `.env*.local`.
- URL (`coverUrl`, `links[].url`) chỉ `http:`/`https:`. Comment ≤ 2000 ký tự. Rating là số nguyên 1–5. 20 sách/trang.
- Không dùng `dangerouslySetInnerHTML`. Ảnh bìa dùng `<img>` thường.
- Hiệu ứng chỉ CSS/Tailwind, tắt dưới `prefers-reduced-motion`. Không thêm thư viện animation/UI.
- Mọi Server Action admin gọi `requireAdmin()` đầu tiên; action review gọi `requireUser()`.
- **Lệch so với spec (đã ghi lại):** bảo vệ `/admin` bằng guard trong `src/app/admin/layout.tsx` thay vì middleware (adapter MongoDB không chạy ở edge); Review lưu kèm `userName`, `userImage` để hiển thị không cần join bảng users.

## Review Focus

1. Tiêu đề tiếng Việt có dấu/chữ `Đ` → slug ASCII đúng (`"Đất Rừng Phương Nam"` → `"dat-rung-phuong-nam"`); trùng slug → `-2`, `-3`. (Task 1, Task 2)
2. Ô tìm kiếm nhập ký tự regex đặc biệt (`C++`, `(`, `.*`) không gây lỗi và tìm đúng nghĩa đen. (Task 2)
3. Người không phải admin gọi trực tiếp Server Action admin → bị từ chối, DB không đổi. (Task 4)
4. Review bị ẩn không tính vào `ratingAvg`/`ratingCount` và không hiển thị; gửi review lần hai cập nhật chứ không tạo bản mới. (Task 2, Task 4)
5. `?page=abc`, `?page=-1`, `?page=999` → không lỗi; page < 1 hoặc không phải số thành 1, vượt quá thì trả danh sách rỗng kèm thông báo "Không tìm thấy sách". (Task 2, Task 5)
6. Link tải `/books/<slug>/go/<i>` với `i` âm, không phải số, vượt số link, hoặc slug không tồn tại → 404, không tăng `downloadCount`; chỉ chuyển hướng tới URL lưu trong DB (không nhận URL từ query). (Task 2, Task 5)
